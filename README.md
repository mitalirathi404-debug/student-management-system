# Student Management System

A console-based Student Management System developed using Java and Object-Oriented Programming (OOP).

## Features

- Add student
- View all students
- Search student by ID
- Update student details
- Delete student
- Store student CGPA
- Prevent duplicate student IDs

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- IntelliJ IDEA

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java is installed.
4. Run `Main.java`.
5. Select an option from the menu and enter the required details.

## Learning Outcomes

This project helped me practice Java fundamentals, OOP concepts, ArrayList, loops, methods, conditional statements, and basic CRUD operations.
